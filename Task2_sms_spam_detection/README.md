# Task 2: SMS Spam Detection

## 📖 Problem Statement
The goal of this task is to build a machine learning model that classifies SMS messages as **Spam** or **Ham (Not Spam)**.

---

## 📊 Dataset
- File: `spam.csv`
- Contains labeled SMS messages.

---

## ⚙️ Approach
1. Data preprocessing and cleaning
2. Text vectorization using TF-IDF
3. Train-test split
4. Model training and evaluation

---

## 🤖 Models Used
- Naive Bayes
- Logistic Regression (if applicable)

---

## 📈 Results
- The model achieved good accuracy in detecting spam messages.
- Evaluation done using accuracy and confusion matrix.
