# Task 1: Movie Genre Classification

## 📖 Problem Statement
The objective of this task is to classify movies into different genres based on their textual descriptions using machine learning and NLP techniques.

---

## 📊 Dataset
- Contains movie titles, descriptions, and genres.
- Text data is preprocessed before model training.

---

## ⚙️ Approach
1. Data cleaning and preprocessing
2. Text vectorization (TF-IDF)
3. Model training using classification algorithms
4. Model evaluation

---

## 🤖 Models Used
- Logistic Regression
- Naive Bayes (if applicable)

---

## 📈 Results
- The model successfully predicts movie genres with reasonable accuracy.
- Performance evaluated using accuracy and classification metrics.

---

## 🧠 Conclusion
This task demonstrates how NLP techniques can be applied to classify text-based data effectively using machine learning models.
